# 英雄联盟对局文件同步助手 (LOL Replay Sync) — 已归档

> **⚠️ 项目已停止运行（2026-06-24）**
>
> 由于腾讯云服务器维护成本原因，本项目已停止服务，服务器已清退。
>
> 感谢所有使用过的朋友！代码仓库保留以供参考。

🎮 英雄联盟对局回放文件（.rofl）自动同步到云端，朋友共享、多设备一站式管理。

---

## 历史功能

- **自动同步** — 监听对局文件夹，新 .rofl 文件自动上传到云端
- **云端回放** — 点击「▶ 回放」直接调用 LOL 客户端播放云端录像
- **多设备共享** — 换台电脑登录即拉取，朋友共享对局录像
- **ROFL 元数据解析** — 英雄阵容、模式、时长一目了然
- **批量操作** — 批量下载、批量解析、批量删除

## 技术栈

| 组件 | 技术 |
|------|------|
| 客户端 | Python + PySide6 |
| 服务端 | Python + Flask + SQLite |
| 打包 | Nuitka 编译为原生可执行文件 |
| 部署 | 腾讯云 Ubuntu |
| CI/CD | GitHub Actions 自动编译 |

## 自行搭建

如想自行搭建服务器继续使用，可参考源码中的 `server/app.py` 自行部署后端，修改客户端中的服务器地址即可。
